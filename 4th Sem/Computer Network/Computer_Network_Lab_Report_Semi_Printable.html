1. Connect two computer using straight cable in packet tracer. Verify the connection using Ping Command.(Show all the steps)

Requirement

Cisco Packet Tracer; two PCs; one 2960 switch; two copper straight-through cables; IPv4 addresses in the same subnet.

Theory

A straight-through cable is used to connect unlike Ethernet devices such as a PC and a switch. Connectivity is confirmed when a ping between the two configured PCs receives replies.

Steps

  1. Place two PCs and one 2960 switch in the workspace.
  2. Connect each PC to the switch using a copper straight-through cable.
  3. Assign PC0 192.168.1.1/24 and PC1 192.168.1.2/24.
  4. Wait until both links become active.
  5. Open the Command Prompt on PC0 and run ping 192.168.1.2.
  6. Confirm that all four echo requests receive replies.
